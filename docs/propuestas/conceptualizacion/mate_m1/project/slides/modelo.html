Idea 4 · el modelo

Un modelo, tres preguntas

Un modelo es una fórmula que cuenta una situación. Con él siempre se puede preguntar tres cosas:

1 · EVALUAR

Me dan x, busco y

Con 4 GB, ¿cuánto pago?

20.000 + 500·4

2 · DESPEJAR

Me dan y, busco x

Pagué $23.000, ¿cuántos GB usé?

3.000 ÷ 500 = 6

3 · INTERPRETAR

¿Qué significa?

¿Qué quiere decir el 500? ¿Tiene sentido x negativo?

dominio: x ≥ 0

Antes de resolver una pregunta del taller, el estudiante decide cuál de las tres le están haciendo. Muchas opciones incorrectas son la respuesta a otra de las tres preguntas. El dominio importa: no hay horas negativas ni medio estudiante.
