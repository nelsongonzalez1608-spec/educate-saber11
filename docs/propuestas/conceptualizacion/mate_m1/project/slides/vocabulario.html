Vocabulario de la misión

Nueve palabras para hoy

Variable

lo que cambia (x, y)

Constante

lo que no cambia

Pendiente

lo que sube por cada paso

Intercepto

donde arranca, cuando x = 0

Vértice

el punto más alto o más bajo

Tasa de cambio

cuánto cambia por unidad

Sucesión

números en orden, con una regla

Término general

la regla para la posición n

Dominio

los valores de x que tienen sentido
